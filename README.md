# Веб-приложение для изучения испанского языка

> Экспериментальное веб-приложение для изучения испанского языка с помощью распознавания речи в реальном времени, перевода фраз и изучения языка в контексте.

**Статус проекта:** 🚧 В разработке

---

## Запуск 
[speech-henna.vercel.app](https://speech-henna.vercel.app)

## 📖 О проекте

**Spanish Speech Learning App** — это экспериментальное веб-приложение, созданное для изучения испанского языка через **живую речь и фразы в контексте**, а не через отдельные слова.

Приложение использует встроенный в браузер **Web Speech API** для распознавания испанской речи в реальном времени. Пользователь может выбрать незнакомую фразу непосредственно из распознанного текста и получить её перевод на русский язык с помощью **DeepL API**.

Перевод отображается непосредственно рядом с оригинальным текстом, поэтому пользователю не нужно покидать страницу или переключаться между приложениями.

В настоящее время проект ориентирован в первую очередь на изучение **аргентинского варианта испанского языка (`es-AR`)**.

## 🔄 Как работает приложение

Приложение построено вокруг простого процесса обучения:

```text
┌─────────────────────┐
│ Пользователь        │
│ говорит по-испански │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Web Speech API      │
│ Распознавание речи  │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Распознанный текст  │
│ отображается на     │
│ странице             │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Пользователь        │
│ выбирает фразу      │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ DeepL API            │
│ Испанский → Русский │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ Перевод отображается│
│ как подсказка       │
└─────────────────────┘
```

Таким образом, пользователь может:

1. Говорить или слушать испанскую речь.
2. Видеть распознанный текст в реальном времени.
3. Выбрать незнакомую фразу.
4. Получить её перевод.
5. Продолжить изучение языка, сохраняя оригинальную фразу и её контекст.

## 🚀 Установка и запуск

### Требования

Для запуска проекта потребуется:

* Python 3;
* современный браузер с поддержкой Web Speech API;
* микрофон;
* разрешение браузера на использование микрофона;
* API-ключ DeepL для работы функции перевода.

---

### Клонирование репозитория

Клонируйте репозиторий:

```bash
git clone https://github.com/mrMoish/speech.git
```

Перейдите в директорию проекта:

```bash
cd speech
```

Запустите локальный HTTP-сервер:

```bash
python3 -m http.server 8001
```

После этого откройте приложение в браузере:

```text
http://localhost:8001
```

При первом запуске разрешите браузеру доступ к микрофону.

## 🌐 Совместимость с браузерами

Работа распознавания речи зависит от браузера, операционной системы и устройства.

В текущей версии проекта используется:

```javascript
webkitSpeechRecognition
```

Поэтому поддержка различных браузеров может отличаться.

Особенно сильно различия могут проявляться на мобильных устройствах при работе с:

* непрерывным распознаванием речи;
* разрешениями на использование микрофона;
* виртуальной клавиатурой;
* динамической высотой viewport;
* выбором текста через сенсорный экран;
* встроенными браузерами приложений, например Telegram.

Кроссбраузерная и кроссплатформенная совместимость находится в процессе разработки.

## ⚠️ Известные ограничения

Проект находится на стадии разработки и имеет следующие ограничения:

* Поддержка Web Speech API зависит от браузера.
* `webkitSpeechRecognition` поддерживается не всеми браузерами.
* Непрерывное распознавание работает по-разному на мобильных устройствах.
* Для работы распознавания требуется разрешение на использование микрофона.
* Текущая версия ориентирована преимущественно на обучение по направлению испанский → русский.
* Выбор текста через сенсорный экран может работать по-разному на разных устройствах.
* Виртуальная клавиатура может изменять высоту viewport приложения.
